# AI Sales OS v5.19.1

## Windows 启动修复

- 修复 Windows 5.19.0 更新后启动时出现 `TypeConverterMarkupExtension` 错误、主窗口无法打开的问题。
- 根因是 5.19.0 品牌派生脚本把多尺寸图标帧错误地拆成了单字节条目，生成的 `.ico` 无法被 WPF 的 Windows Imaging Component 解码。
- 新图标继续使用 5.19.0 已确认的原创品牌母版和相同外观，仅修复 Windows 图标容器与帧编码。

## 连带异常修复

- 修复主窗口在 XAML 初始化中断后关闭时再次出现 `Object reference not set to an instance of an object` 的问题。
- 半初始化窗口现在只执行安全清理，不再访问尚未建立的服务、页面和事件订阅。

## 发布门禁

- Windows 桌面回归新增 WPF 图标解码验证，损坏或不兼容的 `.ico` 会阻止发布。
- Windows 安装包冒烟测试不再只检查进程仍在运行；现在必须确认真正进入 AI Sales OS 主窗口，错误对话框或提前退出都会失败。

## 发布边界

- 本补丁仅发布 Windows x64 简体中文安装包、Velopack 自动更新资产和 Bridge 对应源码。
- macOS 与 PWA 的代码、版本号、构建和发布均保持冻结。
- 不关闭、重启、安装或覆盖本机正式程序。
