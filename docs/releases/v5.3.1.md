# AI Sales OS v5.3.1

## AI 建议结构化输出容错与安全降级

- 修复 WhatsApp Inbox 点击“立即生成建议”后，模型返回轻微非标准 JSON 即弹出 `invalid_structured_output` 的问题。
- 自动兼容 `result` / `data` / `output` / `response` 包裹、常见字段别名、snake_case 字段与枚举、单值数组及百分比置信度，同时继续执行证据、安全和 CRM 字段白名单校验。
- 结构校验失败后最多进行三轮生成；后续轮次会携带上一轮待修复输出和具体校验提示，要求模型定向补齐结构。
- 为结构化建议预留 2200 个输出 token；跨账号会话上下文限制为最近 80 条、单条最多 1200 字符，最新客户原话最多 4000 字符，降低长会话挤占输出空间和 JSON 被截断的概率。
- 手动生成连续失败时生成不包含价格、库存、折扣、交期、物流或政策承诺的可编辑安全确认草稿，不再向普通用户展示内部错误类型。
- 安全降级草稿不会更新 CRM、客户需求或客户关系事实，也不会获得自动发送权限；协作和自动回复后台处理仍严格失败关闭。
- Provider 网络、鉴权或限流失败会恢复按钮并保存为可重试状态。

## 升级与数据安全

- 升级不会覆盖 `%LOCALAPPDATA%\WAFlow\waflow.db`、客户资料、WhatsApp 账号、消息、API 配置、邮件账号、自动化任务、Windows 凭据或知识库数据。
- 本版本仅发布 GitHub Windows 中文安装包和 Velopack 自动更新资产，不覆盖、关闭、重启或安装本机正式程序。
- macOS 构建、安装包与 Release 资产继续暂停。
