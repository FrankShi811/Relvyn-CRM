# AI Sales OS v5.5.6

发布日期：2026-07-28

## 本次更新

- 修复导入新表后打开客户编辑窗口时出现 `StaticResourceExtension` 异常的问题。
- 客户列表、客户编辑、邮件侧栏、自动化字段、AI 字段与报告统一使用“国家”；兼容“国家/地区”“国家/邮箱”和 `country/email` 等旧表头。
- 同一客户 ID 的重复导入改为增量合并：
  - 新表中出现的字段更新同一客户旧值，空值也可清空旧值。
  - 新列自动加入客户维度。
  - 新表未包含的旧列继续保留，不再被整表清空。
  - 同义国家表头更新同一维度，不重复增加竖列。
- 新客户 ID 正常新增客户；客户 ID 缺失时才安全回退到标准化电话号码；身份冲突继续失败关闭。
- 客户编辑窗口将系统字段别名合并到唯一编辑项，保存后同步回原始表头，既避免重复列，也保留导入审计数据。

## 验证与数据安全

- Release 构建、原生冒烟、客户 ID 增量重导入、国家别名、客户编辑窗口和亮暗主题回归均通过。
- 安装与自动更新继续创建或修复桌面快捷方式。
- 升级不会覆盖 `%LOCALAPPDATA%\WAFlow\waflow.db`、WhatsApp/邮箱账号、API 配置、客户、消息、知识库、自动化或报告数据。
- 本版本只发布 Windows 中文安装包与 Velopack 自动更新资产；macOS 发布继续暂停。
