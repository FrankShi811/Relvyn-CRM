# AI Sales OS v5.19.2

## WhatsApp 标签展示与回传链路

- 修复标签窗口中“创建”按钮被永久禁用的问题：输入有效名称且 WhatsApp 账号已连接后即可创建，支持 Enter、同名提示与操作中防重复点击。
- 左侧会话列表和客户列表统一显示 WhatsApp 原生标签彩色小卡片，最多显示前两个并以 `+N` 收纳其余标签；客户标签使用批量联表查询，避免逐客户读取。
- 会话标签筛选改用标签 ID，避免同名标签造成筛选串联。
- 移除 WhatsApp 右侧客户资料栏中视觉重复的 CRM 标签输入框。底层 `Lead.Tags` 历史数据与其他 CRM、导入、Campaign 用途继续保留，并明确显示在客户列表的“CRM 标签”列；保存客户资料不会再覆盖它。
- 修复 WhatsApp 事件使用 `@lid` 联系人标识时，标签关联无法映射到 OS 手机号会话的问题；关联先于号码映射到达时会进入有界等待队列并在映射事件到达后按顺序回放，消息级标签不会被误写成客户标签。
- 标签添加、移除、创建和删除的状态文案改为“已提交 WhatsApp，请在手机端确认”，不再把 Bridge 请求成功或本地事件回显描述成手机端已显示。

## Windows 图标

- Windows 桌面程序、任务栏、快捷方式与安装包图标更新为新的深海军蓝 R/回路箭头标志。
- 仓库保留最终生成母版、唯一参考图、精确编辑提示词、确定性尺寸派生脚本以及所有 Windows PNG/ICO 资产的 SHA-256。
- 新 ICO 沿用 v5.19.1 已验证的 Windows Imaging Component 兼容帧编码，避免再次出现图标导致的 WPF 启动错误。
- macOS 与 PWA 的版本、图标、构建和部署均保持不变。

## 验证范围

- Desktop Release 构建、WPF 图标解码、原生 smoke tests、标签账号隔离、客户批量投影、删除过滤、旧 CRM 标签保留及 Bridge 标签路由必须全部通过。
- Baileys 接受命令、本地 SQLite 写入或 Bridge 事件回显不等于手机端已经显示；Windows 界面会明确提示在真实 WhatsApp Business 手机端确认。
- 正式发布只生成 Windows x64 安装包、Velopack 自动更新资产与 Bridge 对应源码；不关闭、重启、安装或覆盖本机正式程序。
