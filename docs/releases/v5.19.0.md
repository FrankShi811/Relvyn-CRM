# AI Sales OS v5.19.0

## 公司业务与使用角色

- 设置新增公司业务与使用角色。用户可以直接选择通用模板，也可以填写自定义角色。
- 保存后自动应用于 Customer Brain、客户外部调查、商机智能、WhatsApp、邮件箱、自动化、报告与其他结构化 AI 分析，无需逐个模块重复设置。
- AI 仅在客户事实或用户设置明确时使用具体行业、平台和经营模式。

## 全局中立化

- 固定界面文案、引导、导入提示、客户分析和沟通建议统一采用平台与行业中立表述。
- 不再默认假定用户属于特定销售渠道、供应模式、商品形态或目标市场。
- 历史字段别名与数据兼容键继续保留，仅用于旧数据无损升级，不作为对外产品定位。

## 原创品牌素材

- Windows、macOS 与 PWA 应用图标替换为新的原创生成资产。
- 仓库保存确切提示词、未经修改的生成母版、确定性派生脚本以及每个 PNG/ICO 文件的 SHA-256 清单。
- 生成过程未使用参考图片、库存素材或第三方品牌标志。

## WhatsApp Bridge GPL 分发

- `WAFlow.WhatsApp.Bridge.exe` 改为独立 GPL-3.0-only 伴随组件，不再嵌入 `AISalesOS.exe`。
- GitHub Release 同步提供 `AI-Sales-OS-WhatsApp-Bridge-5.19.0-source.zip`，包含对应 Bridge 源码、解析后的依赖源码、构建脚本、锁文件、GPL 文本、安装信息和 SHA-256 清单。
- 设置 `AI_SALES_OS_WHATSAPP_BRIDGE_PATH` 后，可运行用户自行编译或修改的 Bridge；不要求厂商签名或厂商哈希。
- 发布门禁会检查 Bridge 分离、源码归档、许可证、替换机制、品牌来源记录和最终安装目录。

## 发布边界

- 仅发布 Windows x64 简体中文安装包、Velopack 自动更新资产和 Bridge 对应源码。
- 不关闭、重启、安装或覆盖本机正式程序。
- 安装或更新后继续创建或修复桌面与开始菜单快捷方式。
- 更新缓存继续只保留当前、待安装新版本和最近 3 个回滚版本。
- macOS 构建继续暂停。
