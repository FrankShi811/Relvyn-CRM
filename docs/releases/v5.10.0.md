# AI Sales OS v5.10.0

## 自适应悬浮侧栏

- 左侧导航默认收起为 60 像素图标轨道，鼠标悬停或使用键盘导航时平滑展开至 240 像素。
- 展开侧栏覆盖在页面上方，不推动、压缩或改变主内容区域的位置与宽度；鼠标移出后自动回缩。
- 导航选中项取消外围边框，仅保留语义底色和左侧短状态条；键盘焦点使用不包围选项的短划线。

## 统一丝滑交互

- 侧栏展开与收起支持中途反向，并从当前渲染状态连续接管；菜单文字、位移、阴影与宽度分层过渡。
- 按钮增加轻量悬停抬升和按压回弹，页面切换使用短退场与柔和入场，快捷操作弹层增加淡入、位移、缩放与焦点恢复。
- 所有新增动画尊重 Windows“减少动态效果”设置，不使用持续循环或影响信息读取的装饰动画。

## 亮暗主题与信息完整性

- 重新校准白天和夜间的文字、按钮、侧栏、卡片与状态色对比度，夜间 Logo 使用灰色承托底。
- 客户列表补齐客户 ID、公司和邮箱固定列，并扩大 WhatsApp 状态、标签、负责人和一级品类等关键维度宽度。
- 右上角仅保留 AI 配置状态与本页使用手册；左侧底部只保留设置，版本与更新统一移入设置窗口。

## 数据与发布边界

- 升级不覆盖 `%LOCALAPPDATA%\WAFlow\waflow.db`、客户、原始字段、消息、WhatsApp/邮箱账号、API Key、知识库、自动化或报告数据。
- 仅发布 GitHub Windows 中文安装包和 Velopack 自动更新资产；安装或更新继续创建或修复桌面快捷方式。
- 不直接覆盖、关闭、重启或安装本机正式程序；macOS 正式发布继续暂停。
