# AI Sales OS v5.16.0

## 商机补充数据导入

- 商机智能新增独立的“导入商机数据”，用于导入包含成功交易、失败交易、待付款交易和争议交易明细的商机补充数据工作簿。
- 只处理与客户列表客户 ID 完全匹配的现有客户；不按姓名或电话猜测，不创建客户，也不修改客户姓名、电话、邮箱、负责人、人工备注或手动锁定阶段。
- 导入前展示文件行数、命中客户与事件、未匹配数据、客户 ID 冲突、重复事件及将被刷新的客户；确认后在单一事务中提交，失败时整体回滚。
- 同一文件或同一交易事件重复导入时，不重复写入交易证据，也不重复触发 AI 或消耗 Token。

## 交易证据与商机快照

- 本地保存逐笔交易证据，并按客户汇总成交金额、交易数、平均交易价值、近期成功交易、待付款、交易失败、争议风险、一级品类偏好和高频产品或服务。
- 商机队列继续保持“客户、市场、等级、AI 分数、阶段、分析状态”六列，避免表格横向膨胀。
- AI Decision Brief 新增交易价值、近期合作意图、品类画像、支付障碍、争议风险和最近交易证据。
- 商机队列新增意图/风险、最近交易活动、一级品类和累计支付金额筛选，并继续支持 10、30、50 条分页。

## 增量 AI 与数据安全

- 汇总、去重和数学计算均在本地完成；只有交易快照实际变化的客户才进入商机智能增量分析队列。
- 客户 ID 在客户主档中存在重复归属时，该客户 ID 会停止导入并列入冲突清单，避免错误合并。
- 升级不会覆盖客户、消息、WhatsApp/邮箱账号、API Key、知识库、自动化、报告、本地数据工作区或 SQLite 数据。
- Windows 安装或更新后继续创建或修复桌面快捷方式；更新缓存继续只保留当前、待安装新版本及最近 3 个回滚版本。
- 本版本只发布 GitHub Windows 中文安装包与 Velopack 自动更新资产，不直接修改本机正式程序；macOS 发布继续暂停。
