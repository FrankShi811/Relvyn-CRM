# AI Sales OS v5.5.7

发布日期：2026-07-28

## 本次更新

- 修复客户列表横轴最右侧出现重复动态维度的问题：
  - 同名、大小写或标点不同、带换行说明及带 `(2)` 后缀的等价表头只展示一列。
  - 合并列从所有等价原表字段中读取首个非空值，排序和维度筛选保持一致。
  - 原始字段和值仍完整保留，不迁移、不覆盖客户数据。
- 修复动态维度表头显示空白的问题：
  - 历史不可见表头显示为“未命名维度 N”并保留原值。
  - 新导入表格会清理零宽字符和格式控制符，空白表头自动命名为“未命名列 N”。
- 客户 ID、客户名、国家、电话、邮箱等系统字段及旧表别名继续只显示在固定系统列，不会重复进入动态维度区。

## 验证与数据安全

- Release 构建、原生冒烟、重复表头合并、不可见表头、新表空白表头、排序和筛选回归均通过。
- 安装与自动更新继续创建或修复桌面快捷方式。
- 升级不会覆盖 `%LOCALAPPDATA%\WAFlow\waflow.db`、WhatsApp/邮箱账号、API 配置、客户、消息、知识库、自动化或报告数据。
- 本版本只发布 Windows 中文安装包与 Velopack 自动更新资产；macOS 发布继续暂停。
