# AI Sales OS v5.2.1

## Customer Success 卡片展示精简

- 移除“关联账号”“主账号”和“本账号关系”三类内部信息展示。
- Customer Success Agent 卡片只保留客户身份状态、工作模式、模式说明和最近一次 Agent 产出，减少无业务价值的账号技术信息。
- 不使用其他提示或占位文字替换被删除区域。

## 跨账号统一客户上下文保持不变

- 同一客户在多个 WhatsApp 账号下的已确认身份关联继续保存在本地。
- 所有关联账号的客户消息仍聚合到同一全局客户上下文，并供客户需求、Customer Brain、Agent 建议和客户智能分析使用。
- 客户需求要点、全局关系记忆、待确认问题、人工接管和 Agent 状态继续跨账号同步更新。
- 主账号锁和每账号关系记忆仍在后台用于防止重复自动回复、保持账号身份语气和执行安全，但不再直接展示给用户。

## 验证、数据与发布边界

- 新增双账号消息统一聚合回归，验证从任一账号打开同一客户时都能读取两个账号的最新消息。
- 新增 UI 隐藏契约，防止以后重新暴露账号 ID、主账号或每账号关系摘要。
- 升级不删除或覆盖 `%LOCALAPPDATA%\WAFlow\waflow.db`、客户、WhatsApp/邮件账号、消息、API、自动化、凭据或知识库数据。
- 本版本仅通过 GitHub Release 发布 Windows 中文安装包与 Velopack 自动更新资产，不覆盖、关闭、重启或安装本机正式程序；macOS 构建继续暂停。
