# AI Sales OS brand asset provenance

The distributed AI Sales OS application icon family is derived from a newly generated master retained in `generation-records/`.

The provenance set contains:

- the exact generation prompt;
- the untouched host-native image-generation output;
- a deterministic PowerShell derivation script;
- SHA-256 hashes and byte sizes for every distributed PNG and ICO asset;
- the project owner's explicit authorization to replace the previous unverified assets.

No reference image, stock artwork, marketplace asset or third-party logo was supplied to the generator. The generated output is not represented as a registered trademark or as guaranteed unique against every mark worldwide. A separate trademark clearance review remains appropriate before trademark registration.

Regenerate the derived assets on Windows with:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\generate-brand-assets.ps1
```
