# AI Sales OS v5.19.7

## 邮件对话、角色联动与桌面图标修复

- 邮件箱按真实时间交错显示双方往来，连续收发不再按方向分组；主时间线优先展示清理后的可读正文和少量图片，冗长链接与完整营销邮件统一收纳到“查看原邮件”。

- 桌面快捷方式改为原子重建并主动刷新 Windows Shell 图标缓存；安装门禁逐像素核验快捷方式图标与受保护品牌基准。
- 已通过 Windows Release 构建、Core/Bridge 回归、真实隔离安装、快捷方式与 125% DPI 图标门禁。本补丁只发布 Windows x64 桌面程序、独立 WhatsApp Bridge、简体中文安装包和 Velopack 自动更新资产；macOS 与 PWA 的代码、版本、图标、缓存、构建和发布保持不变，也不会关闭、重启、安装或覆盖本机正式程序。
