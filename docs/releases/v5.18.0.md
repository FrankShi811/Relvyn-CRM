# AI Sales OS v5.18.0

## 客户外部调查与客户数据统一

- Customer Operations 新增“客户外部调查”。用户可直接选择客户或从客户列表进入，对该客户的公开商业信息发起调查、查看来源与证据、审核冲突，并形成供 Customer Brain 与客户智能报告使用的可审核事实。
- Tavily、Brave 或用户明确启用的本地 SearXNG 会按可用性自动选择，普通用户不需要手工排序服务商。首次使用只展示当前能否调查和一条下一步操作。
- 未配置公开搜索服务时，页面提供简明配置入口；填写一个自己的 Tavily 或 Brave 搜索密钥即可收集公开来源。把来源进一步整理为 Customer Brain 事实只需显式开启 AI 事实整理并填写本程序本地月度估算提醒额度，每次估算预留留在高级选项并自动采用默认值；默认提醒额度为 0，付费搜索与 AI 事实整理保持关闭。
- 调查用量的日/月账期统一按用户本地时区记录，避免月初因 UTC 与本地日期不一致而漏计。本地额度、单价、预留和累计金额均仅统计本机调用，不含 Provider 账号在其他工具中的用量；实际套餐、额度、定价和账单以 Provider 为准。
- 调查事实以同一客户 ID 进入 Customer Brain 和客户智能分析来源。人工确认前不会静默覆盖 CRM 原始字段，冲突信息会保留证据并交由用户审核。
- 客户 ID、电话或邮箱发生身份变化后，旧身份事实与旧报告立即标记为过期；进行中的旧身份任务不会回写当前客户。
- Customer Brain、今日简报和客户智能分析统一读取客户身份关联后的 WhatsApp 与邮件上下文。外部事实变化会使旧决策和旧报告失效，不能继续当作当前结论展示或导出；历史版本仍完整保留以供追溯。
- WhatsApp、邮件箱、Customer Success Agent 与邮件 Campaign 的 AI 内容均绑定生成时的客户身份、会话和有效调查事实。发送期间如发生客户重绑、客户资料变更、新消息接管或调查事实变化，服务器已确认的消息会永久按未关联记录，并与所有客户 Brain、状态、知识反馈和分析来源隔离；界面明确提示不要重复发送。
- 左侧导航将“客户列表”移入 Command Center，“客户外部调查”保留在 Customer Operations；用户可见名称同步改为“看板”“WhatsApp”“邮件箱”，内部模块键与已有客户、消息和设置数据保持兼容。
- 新增客户调查身份隔离、并发回写拦截、跨账号消息、陈旧决策与报告、单值事实冲突、批量状态和导航回归。

## 数据与隐私边界

- 调查只使用公开网页信息和用户自己配置的搜索服务，不内置开发者共享密钥，也不自动安装 Docker 或本地搜索服务。
- API Key 继续保存在当前 Windows 用户的凭据管理器；客户数据、证据、报告和审核记录继续保存在用户自己的本地数据工作区。
- 外部信息作为带来源、时间、置信度和身份快照的证据进入分析，不会未经人工确认覆盖客户列表原始字段。
- 升级不会删除或覆盖客户、原始字段、消息、WhatsApp/邮箱账号、API Key、知识库、自动化、报告、设置或 SQLite 数据。

## 发布边界

- 仅发布 GitHub Windows 中文安装包与 Velopack 自动更新资产，不关闭、重启、安装或覆盖本机正式程序。
- 安装或更新继续创建或修复桌面快捷方式。
- 更新缓存继续只保留当前、待安装新版本及最近 3 个回滚版本。
- macOS 发布继续暂停。
